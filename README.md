# befcs-media

예수전도단 독수리가정상담학교(BEFCS) 야간(토요일반) 홍보 게시용 공개 파일 저장소입니다(2026-11-24).
SNS 예약 서비스(Metricool)가 게시 시각에 이 저장소의 공개 주소에서 영상·그림을 가져갑니다.

- 넣는 것: 게시가 승인된 영상(mp4)·그림(png·jpg)만. 폴더는 `posts/<게시 id>/`.
- 넣지 않는 것: 글, 간증, 신청서 자료, 원자료, 사진 원본, 승인 전 파일, 개인 연락처가 든 그림.
- 공개 저장소이므로 한 번 올린 파일은 지워도 이력에 남습니다. 올리는 순간 공개된 것으로 봅니다.
- 관리 규칙: 비공개 작업 저장소의 `automation/AUTO_POST.md` 1-2절. 파일은 `tools/metricool_post.py`가 넣습니다.
- 모음 화면(2026-11-25 간사 승인): 맨 위 `index.html`과 `assets/`는 SNS 5곳 프로필의 첫 링크로 쓰는 화면입니다(주소 https://limjc9-sys.github.io/befcs-media/ , 끝에 `?from=yt|ig|fb|kakao|blog|home`을 붙이면 신청서의 「어디서 보고 오셨나요?」가 미리 골라집니다). 내용은 비공개 작업 저장소 `materials/key_facts.md`의 확정값만 씁니다.
